books = [

    {"title" : "Love yourself", "author": "Hema"}
]
for book in books:
    print(f"{book['title']} by {book['author']}")

**A for loop runs once for each item in a collection. It knows exactly how many times it'll run — one per item. ("For each song, print it.")

**A while loop runs as long as a condition stays true. It doesn't count items — it keeps going until something changes. ("Keep going while I still have battery left.")

So for = "do this for every item." while = "keep doing this until a condition becomes false."


Use for when you know the collection or count ("for each of these 4 songs").
Use while when you don't know how many times — you loop until something happens ("keep asking the user for input until they type 'quit'", "keep retrying the API until it succeeds"). This "keep going until X" pattern is common in real AI apps.
