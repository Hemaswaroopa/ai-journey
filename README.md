# Expense Tracker

Built as my first project while transitioning from marketing to AI engineering. This Expense Tracker is to track user daily expenses and analyse user spending.

## Features
1. Add an expense- record what an user has spent, how much, category(food, transport,etc)
2. View all expenses- list everything which has been recorded.
3. See the total- how much overall spent
4. See a category breakdown- how much category


## What I Learned
Functions — organizing code into reusable pieces (add, view, total, breakdown)
List of dictionaries — storing multiple expense records, each with several fields
The accumulator pattern — building up a total and per-category breakdown while looping
Scope — keeping the shared expenses list accessible to all functions
Debugging — reading error messages and fixing my own bugs
